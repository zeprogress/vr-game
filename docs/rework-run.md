# Как поднять сервер ветки `rework`

Локальный запуск копии игры для проверки реворка. Клиент и сервер — те же, что
в `main`, но сейвы лучше держать отдельно: реворк меняет кривую опыта и дерево,
и `players.json` мигрируется при первом запуске.

## 1. Ветка и зависимости

```bash
cd "/Users/zep/VR GAME"
git switch rework
git pull                       # если ветка есть на сервере
npm install                    # если node_modules ещё нет
```

## 2. Сервер без сейвов (рекомендую)

```bash
npm run server:rework
```

Это `PLAYERS_FRESH=1` + временный `ZEP_DATA_DIR`: сервер **не читает и не пишет**
`players.json`, а мир, чат и инвентарные сессии идут во временную папку
`/tmp/zep-rework.*`. Каждый запуск — чистый мир, без старых героев и без
миграций XP/дерева. Сервер слушает **:2567**.

Если нужны отдельные сейвы именно для реворка (чтобы прогресс переживал
перезапуск, но не трогал основную ветку):

```bash
npm run server:rework:save
```

Это `ZEP_DATA_DIR=src/server/.data/rework`: **все** данные реворка (герои, мир,
чат, инвентарь, логи) лежат в `src/server/.data/rework`, основная ветка их не
видит. Миграции XP/дерева касаются только этого каталога.

Если хочешь играть на своих текущих сейвах основной ветки — сначала сделай
резервную копию и запускай обычный сервер:

```bash
cp src/server/.data/players.json src/server/.data/players.json.bak-before-rework
npm run server
```

Помни: после этого `main` тоже увидит мигрированные сейвы. Для чистого
реворка используй `server:rework`.

## 3. Клиент

Второй терминал:

```bash
npm run dev          # обычный HTTP, http://localhost:5173
# или
npm run dev:vr       # HTTPS для Quest/телефона, https://localhost:5173
```

Vite проксирует `/matchmake`, `/api` и WebSocket комнаты на `:2567` — отдельный
адрес сервера в клиенте указывать не нужно. Открой `http://localhost:5173`.

Для шлема: запусти `npm run dev:vr`, возьми IP из строки Network и открой
`https://<IP>:5173` в Quest (сертификат самоподписанный — прими предупреждение).

`start.command` / `share.command` поднимают **обычный** `npm run server`, без
отдельного файла сейвов. Для реворка используй команды выше; для туннеля
другу — `npm run tunnel` при уже запущенном клиенте.

## 4. Вход

Обычные ники пускаются только после кода из Twitch-чата. Для локальной проверки
проще админ-ник и пароль:

```bash
ADMIN_PASS=любой-пароль npm run server:rework
```

На экране входа: ник `zep` (или `zeprogress`), пароль — тот, что задал в
`ADMIN_PASS`. Новому герою выбери класс в списке на экране входа: он фиксируется
навсегда, умения работают только с оружием этого класса.

## 5. Суперпользователь `zep`

После входа под админ-ником (`zep`, `zeprogress`, `bearmood_tv`) команды работают
и из Twitch-чата, и прямо из чата героя в игре. Обычным никам они недоступны.

| Команда | Что делает |
|---|---|
| `!setlevel 100` | любой уровень 1–100; очки дерева пересчитываются, HP/мана — полные |
| `!give scrap 1000000` | ресурс в сумку; можно `potion`, `fish`, `scroll_xp`, `scroll_wind` |
| `!give potion 99` | 99 зелий (или другое число) |
| `!give all` | по максимуму всех ресурсов, сколько влезет в сумку |
| `!weapon sword ruby` | выдать и надеть оружие: `sword/bow/staff/dagger/spear/hammer/shield` |
| `!weapon all ruby` | все классы + щит на склад |
| `!armor all ruby` | все пять частей брони, сразу надеть |
| `!armor chest legendary` | одна часть: `helm/chest/gloves/legs/boots` |
| `!god` | 100 ур., все рубиновые оружия и броня, полная сумка ресурсов |

Тиры: `base`, `gold`, `legendary`, `ruby`, `craft`; можно по-русски: `золото`,
`уник`, `рубин`, `крафт`. Ресурсы: `scrap` (лом), `fish`, `potion`, `scroll_xp`,
`scroll_wind`; русские алиасы — `лом`, `рыба`, `зелье`, `мудрость`, `ветер`.

Если понизить уровень ниже уже взятых узлов дерева, дерево этого класса
сбрасывается и очки возвращаются. Повышение уровня дерево не трогает.

## 6. Быстрая проверка

```bash
npm run typecheck
npm test
npm run lab:check
npm run lab:balance -- --quick --only skills --lvl 33
```

`ZEP_DATA_DIR=...` переносит все данные сервера; `PLAYERS_FILE=...` — только
`players.json`; `PLAYERS_FRESH=1` — вообще не читать и не писать сейвы героев. Лаборатория: `npm run lab` →
`http://localhost:5173/lab.html?s=skills`.
Порт сервера меняется только через `GAME_SERVER_PORT`; тогда прокси Vite тоже
нужно править — по умолчанию не трогай.
