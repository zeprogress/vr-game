# Пайплайн моделей: персонажи, мобы, пропы

Цель — модели в стиле игры (низкополи, плоские цвета, как паки Quaternius), с анимациями, в бюджете
Quest и спектатора, **без ручной возни в Blender и дёшево по токенам**. Всё делается скриптами Blender
без интерфейса: `npm run asset -- <команда>` (обёртка `scripts/asset.mjs`, скрипты в `tools/blender/`).
Каждый шаг отдаёт короткий JSON; визуально — одна картинка-лист 512×512.

## Бюджеты (проверяет `prep`, пишет в `warnings`)

| Что | Треугольники | Кости | Материалы | Текстуры | Клипы |
|---|---|---|---|---|---|
| Герой / скин | ≤ 5 000 | ≤ 64 | ≤ 8 | нет (палитра) | Idle, Walk, Run, Attack, HitReact, Death (+ свои) |
| Моб обычный | ≤ 3 000–5 000 | ≤ 64 | ≤ 8 | нет | Idle, Walk, Run, Attack, HitReact, Death |
| Страж / босс | ≤ 10 000 | ≤ 64 | ≤ 10 | нет | + особые атаки |
| Проп / деталь кита | ≤ 300–2 000 | — | ≤ 4 | нет или атлас ≤ 1K | — |
| Оружие | ≤ 1 500 | — | ≤ 4 | нет | — |

Почему без текстур: игра перекрашивает модели по цвету материала (`recolorFlat` / `recolorCharacter`),
плоские цвета — это наш стиль, а файлы в 3–5 раз меньше.

Соглашения: метры; ступни на 0; модель смотрит «спереди» (−Y в Blender, `prep --rotz` поворачивает);
одно Armature на модель; клипы называются как в таблице (`prep --clips/--keep`).

## Откуда брать модель (по цене)

1. **CC0-паки в стиле игры** — бесплатно, сразу с ригом и анимациями, стиль совпадает:
   Quaternius (Ultimate Monsters, Ultimate Animated Characters, RPG, Animals — уже в игре),
   KayKit (Kay Lousberg: персонажи с общим скелетом, подземелья), Kenney, Poly Pizza (смотреть лицензию:
   CC0 — можно всё, CC-BY — с указанием автора). Скачивание файлов — только с согласия пользователя.
2. **Генерация по референсу (image-to-3D)**: Meshy, Tripo, Hyper3D Rodin, Hunyuan3D. Нужен аккаунт/ключ
   и бюджет на кредиты. На выходе плотная сетка с текстурой — `prep --tris … --palette 8` переводит её
   в наш стиль. Риг: авто-риг самих сервисов (гуманоид/четвероногий, сразу с клипами) или Mixamo
   (гуманоиды, загрузка вручную).
3. **Процедурно скриптом Blender** — камни, ящики, бочки, знамёна, колонны, решётки: Claude пишет
   генератор (параметры → меш), это дешевле и точнее генерации.

## Шаги

1. **Бриф**: картинка-референс + текст — роль (моб 33 ур., страж, скин), рост в метрах, цвета, особые
   анимации. Пример: «Костяной голем, 3.2 м, кость + ржавое железо + зелёное свечение в глазах».
2. **Источник** — по списку выше; файл кладём в `tools/inbox/` (не в репозиторий, папка в .gitignore).
3. **Осмотр**: `npm run asset -- inspect tools/inbox/golem.glb` — треугольники, материалы и цвета,
   текстуры, кости, клипы с длиной, рост, «бесхозные» служебные меши.
4. **Подготовка** под игру одним прогоном:
   ```
   npm run asset -- prep tools/inbox/golem.glb public/models/monsters/BoneGolem.glb \
     --height 3.2 --tris 6000 --palette 8 --merge \
     --clips "Idle_=Idle,Walk_=Walk,Run_=Run,Punch_=Attack,HitReact_=HitReact,Death_=Death" \
     --keep Idle,Walk,Run,Attack,HitReact,Death
   ```
   Удаляет служебные меши, масштабирует, ставит на землю, урезает треугольники (Decimate, веса
   костей сохраняются), текстуру → K плоских цветов (k-means по граням, текстуры удаляются),
   переименовывает и отбирает клипы, сливает меши одного скелета, выгружает GLB, проверяет бюджеты.
5. **Превью**: `npm run asset -- preview public/models/monsters/BoneGolem.glb /tmp/golem.png --anim Attack`
   — 4 ракурса + 4 кадра клипа одной картинкой. Не нравится — правим параметры шага 4, а не руками.
6. **В игру**: путь в `MODELS` (`src/client/world/models.ts`), моб — в `ELITE_MOBS` (`model`, `scaleMul`),
   скин героя — в `BOT_SKIN_MODELS`. Проверка на стенде (`npm run stage`), для VR — Quest (metavr).
7. Коммит; на прод — по «деплой».

## Правила экономии токенов (для Claude)

- Модель не открывать в интерфейсе и не читать файл: только `inspect` (JSON) и одна картинка `preview`.
- Править параметрами шага `prep` и перезапуском, а не серией ручных операций.
- Пачкой: несколько моделей — один скрипт/цикл, итог — таблица.
- Blender MCP (живой Blender, порт 9876) — только для совместной доводки с пользователем: он
  запускает Blender и включает аддон MCP. Для пакетной работы MCP не нужен — хватает CLI.

## Ограничения и подсказки

- Shape keys мешают Decimate (меш пропускается с предупреждением).
- Палитра считается по цвету текстуры в центре грани: мелкие детали (глаза, руны) могут слиться —
  подними `--palette` (10–12) или оставь отдельный материал на светящиеся части.
- Разные скелеты = разные клипы. Для общей библиотеки анимаций нужен один скелет на группу
  (как у паков Quaternius/KayKit) — так клипы переносятся между моделями без ретаргета.
