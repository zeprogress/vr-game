# Модели с нуля: мобы, боссы, герои, пропы

Тело «лепится» из форм-примитивов, которые плавно сливаются (как пластилин): эллипсоиды, капсулы-конусы,
сферы, скруглённые коробки, торы. Из поля форм строится сетка (surface nets), прореживается под бюджет,
красится по материалам форм. Скелет — из шаблона, веса — по тем же формам (каждая форма знает свою кость),
клипы — процедурные (замах → удар → возврат, шаг с IK стоп). Жёсткие детали (глаза, зубы, рога, оружие,
пряжки) — отдельные чёткие меши, привязанные к кости целиком.

Стиль игры — стилизованные «пластилиновые» мобы с плоскими цветами (как пак Ultimate Monsters):
гладкие формы, утрированные пропорции, 3–6 цветов + акцент. У мобов и боссов все цвета запекаются в
крошечную палитру-текстуру (клетка 16×16 на цвет, ~0.5 КБ) — **один материал = одна отрисовка на моба**,
как атлас у пака (`recolorMonster` работает с ним так же); `"atlas": false` — оставить материалы.
Герои — с материалами, как модели героев пака.

## Цикл работы

1. **Бриф** от пользователя: кто это (моб 30 ур., страж, босс, скин героя), рост, характер, 2–4 цвета,
   особые движения, референс-картинка (по желанию).
2. **Спецификация** — Claude пишет `art/models/<Имя>.json` (≈40–80 строк): шаблон скелета + пропорции,
   палитра, формы-добавки, детали, стиль атаки.
3. **Сборка + превью**: `npm run asset -- gen art/models/<Имя>.json art/build/<Имя>.glb --preview art/build/<Имя>.png`
   → JSON (треугольники, кости, клипы, рост, предупреждения) + один лист: 4 ракурса и по строке кадров
   на каждый клип. 2–5 с на модель.
4. **Итерации** — правим числа (радиусы, смещения, k, цвета) и пересобираем. Предупреждение
   «слиплись X и Y» = формы несоседних костей срослись (кожа потянется в движении) — развести.
5. **Вместе в Blender** (MCP, по желанию): `build_file(..., live=True)` — модель в открытом Blender,
   пользователь смотрит клипы (пробел), говорит правки.
6. **В игру**: `gen … public/models/gen/<Имя>.glb`; моб — `MODELS` (`src/client/world/models.ts`) +
   `ELITE_MOBS` (`model`, `scaleMul`, `gait: true` — стойка/шаг/бег по скорости; клип `Attack` — удар/бросок
   у `leaper`/`shot`); герой — как скины `BOT_SKIN_MODELS`. Стенд → коммит; на прод — по «деплой».
   Первый в игре — Скалолом (`rockBreaker` → `monBogBrute`).

## Бюджеты (проверяет `gen`)

| Что | `type` | Треугольники | Кости | Материалы |
|---|---|---|---|---|
| Моб | `mob` | ≤ 5 000 | ≤ 64 | ≤ 10 |
| Страж / босс | `boss` | ≤ 10 000 | ≤ 64 | ≤ 12 |
| Герой (скелет игры) | `hero` | ≤ 5 000 | 23 (свой) | ≤ 10 |
| Проп | `prop` | ≤ 2 000 | — | ≤ 4 |

## Спецификация

Координаты — Blender, метры: **X вбок** (+ — левая сторона модели, кости `.L`), **Y назад** (морда смотрит
в −Y), **Z вверх**. Точка: `[x, y, z]`, `"сустав"` или `["сустав", [dx, dy, dz]]`. `"mirror": true` у формы,
детали или кости — зеркальная копия (X → −X, `.L` ↔ `.R`).

```jsonc
{
  "name": "BogBrute", "type": "mob",
  "rig": "biped",            // biped | quad | blob | char | none
  "height": 2.3,             // итоговый рост, м (кроме char — там размеры скелета игры)
  "tris": 5000,              // бюджет (тело прореживается, детали — как есть)
  "mats": {"skin": "#6f8a3c", "metal": {"c": "#8d939a", "metal": 0.6, "rough": 0.5}, "eye": {"c": "#ffb347", "emit": 2}},
  "body": { … },             // параметры шаблона (пропорции, радиусы r, сглаживание k) — см. ниже
  "joints": {"knee.L": ["knee.L", [0, -0.05, 0]]},   // точечные правки суставов шаблона
  "bones": [{"name": "Jaw", "head": ["head", [0, -0.06, -0.04]], "tail": "snout", "parent": "Head", "role": "jaw"}],
  "drop": ["Hand.L"],        // убрать формы шаблона у костей
  "add": [ … ],              // формы-«глина»
  "parts": [ … ],            // жёсткие детали
  "anim": {"attack": "swing", "walk": {"stride": 0.5}},
  "clips": ["Idle", "Walk", "Attack"]   // по умолчанию все 6
}
```

### Шаблоны скелета (`rig`) и их `body`

- **biped** — Hips → Spine → Chest → Neck → Head; Shoulder/UpperArm/LowerArm/Hand; UpperLeg/LowerLeg/Foot (19 костей).
  Суставы: `hips spine chest neck head headTop`, `clav.L shoulder.L elbow.L wrist.L hand.L`, `hip.L knee.L ankle.L toe.L`.
  Пропорции: `legLen torso neck head shoulderW hipW armLen armSpread hunch footLen`.
  Радиусы `r`: `pelvis belly chest head foot hand` — [rx, ry, rz]; `upperArm forearm thigh calf` — [r1, r2]; `neck shoulder` — число.
- **quad** — Hips → Spine → Chest → Neck → Head, хвост Tail1..n, ноги FrontLeg1/2 + FrontFoot, HindLeg1/2 + HindFoot.
  Суставы: `hips spine chest neck head snout tail0..n`, `fShoulder.L fElbow.L fWrist.L fToe.L`, `hHip.L hKnee.L hHock.L hToe.L`.
  Пропорции: `legLen bodyLen neck neckUp head tail tailSegs tailUp hipW chestW footLen`.
- **blob** — Body → Top (слизни, духи, грибы): суставы `base mid top`; клипы — прыжки и сплющивание.
- **char** — **герой на скелете игры**: `"base": "public/models/chars/Knight_Male.glb"` — берём скелет
  CharacterArmature и **все 17 игровых клипов** (SwordSlash, Shoot_OneHanded, Run, Death…), тело лепим своё.
  Суставы — имена костей (`Head`, `Torso`, `Fist.L`…), хвосты — `<Кость>.end`. Поза покоя — T, голова «чиби».
- **none** — проп без скелета.

`k` — радиус сглаживания стыков (больше — мягче, «пухлее»): `{"torso": 0.12, "limb": 0.07, "head": 0.08, …}`.

### Формы (`add`)

| `shape` | Параметры |
|---|---|
| `sphere` | `at`, `off`, `r` |
| `ellipsoid` | `at`, `off`, `r: [rx, ry, rz]`, `rot: [x, y, z]°` |
| `cone` (капсула с разными концами) | `a`, `b` (точки), `r: [r1, r2]`, `off`/`off2` |
| `cyl` | `a`, `b`, `r`, `rnd` |
| `box` | `at`, `h: [полуразмеры]`, `rnd`, `rot` |
| `torus` | `at`, `R`, `r`, `rot` (ремни, браслеты, ошейники) |

Общие: `op` — `add` (слить, по умолчанию) | `sub` (вырезать: рты, глазницы, капюшон) | `paint` (только цвет:
живот, пятна, одежда, сапоги — форма не меняется); `k` — сглаживание; `mat`; `bone` (иначе — кость сустава
`at`/`a` или ближайшая); `noise: [амплитуда, частота, seed]` — бугристость (шерсть, кора, камень).
Порядок важен: формы применяются сверху вниз (вырезать капюшон → вернуть лицо меньшим эллипсоидом).

### Детали (`parts`)

| `shape` | Параметры |
|---|---|
| `sphere` | `at`, `off`, `r` или `[rx, ry, rz]`, `seg` — глаза, зрачки, навершия |
| `horn` / `cone` | `at`, `off`, `dir`, `len` (или `to`), `r` / `[r0, r1]`, `bend: [x, y, z]`, `steps` — рога, клыки, когти, шипы |
| `tube` | `path: [точки]`, `r: [r0, r1]` — щупальца, усы, древки |
| `cyl` | `at`, `dir`, `len`, `r` — рукояти, колчаны |
| `box` | `at`, `h`, `bevel`, `rot` — броня, пряжки, клинки |
| `ring` | `at`, `R`, `r`, `rot` — кольца, обручи |

Деталь целиком привязана к кости (`bone` или кость сустава `at`); `smooth: false` — гранёная.

### Клипы и `anim`

Idle 2 с, Walk 1.07 с, Run 0.67 с, Attack 0.87 с, HitReact 0.53 с, Death 1.33 с (30 к/с). Шаг/бег — IK стоп
(стопа стоит на земле в опоре), просадка таза, наклон корпуса, отмашка рук, запаздывание хвоста.
`anim.attack`: `swing` (рука сверху наискось, по умолчанию у двуногих), `punch`, `slam` (обеими руками),
`bite` (четвероногие, кость с `"role": "jaw"` открывает пасть), `lunge` (слизни).
`anim.walk` / `anim.run`: `stride lift bob crouch duty lean armSwing` (в метрах/градусах; по умолчанию — от длины ног).

## Приёмы качества

- **Силуэт важнее деталей**: узнаваем в 30 px (стрим) — утрировать 1–2 черты (горб, огромные руки, рога).
- **Пропорции персонажа**: большая голова и кисти — «мило/опасно»; маленькая голова на огромном торсе — «громила».
- **Цвет**: 1 основной + 1–2 вторичных + 1 акцент (глаза/руны со `emit`), живот и морда — светлее (`paint`).
- **Чёткие детали — `parts`**, а не формы: глаза, зубы, пряжки остаются чистыми при прореживании.
- **Рты/глазницы — `sub`** с маленьким `k` (0.01–0.03) и своим материалом (тёмный).
- Руки в покое разведены (`armSpread` 20–30°) — иначе формы рук слипнутся с торсом.

## Примеры (art/models)

`BogBrute` — болотный громила (biped, дубина, клыки, рога); `AshWolf` — волк (quad, челюсть, уши);
`BogSlime` — слизень (blob); `HeroRanger` — следопыт в капюшоне (char, все клипы героя).
