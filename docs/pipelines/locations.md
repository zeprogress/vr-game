# Пайплайн локаций: от брифа до игры

Цель — локации уровня «красиво как в большой игре», но в бюджете WebGL/Quest: богатая детализация
за счёт инстансов (тысячи деталей — несколько отрисовок), продуманный свет и атмосфера, понятная
композиция кадра. Сборка — в Blender, выгрузка одним скриптом: `npm run asset -- location …`.

## Что значит «ААА-качество» у нас

- **Арт-направление**: палитра (3–5 основных цветов + акцент), время суток и свет, туман, масштаб
  (герой 1.8 м, двери 3 м, колонны 1–1.5 м), один стиль деталей (низкополи, плоские цвета, как модели).
- **Композиция**: у каждой зоны точка интереса (видна издалека), ведущие линии (тропы, стены, свет),
  смена ритма — открытое/закрытое, светлое/тёмное. Края и переходы обязательны: камни у воды, трава
  у стен, обломки у руин — без «голой» границы.
- **Детализация слоями**: крупные формы → средние (скалы, руины, деревья) → мелочь (камни, кусты, кости,
  свечи, грибы) → декали (грязь, мох, трещины, кровь). Мелочь — scatter по правилам, не руками.
- **Свет**: солнце + небо + немного точечных (Quest: ≤ 4 динамических), остальное — «запечённые»
  пятна света и свечения (как в катакомбах), запекание AO/света в вершинные цвета для статики.
- **Жизнь**: движущиеся элементы (флаги, огонь, вода, пылинки), звук окружения.

## Бюджеты (сводка `location` пишет предупреждения)

| | Quest (VR) | Спектатор 1080p |
|---|---|---|
| Отрисовок в кадре | ≤ 150 | ≤ 300 |
| Треугольников в кадре | ≤ 300–400k | ≤ 800k |
| Динамических источников света | ≤ 4 | ≤ 6 |
| Текстуры | атласы ≤ 2048 | атласы ≤ 2048 |

## Шаги

0. **Бриф и референсы.** 5–10 картинок (мудборд), план сверху: зоны, тропы, точки интереса, откуда
   приходит игрок, где бой, где отдых, где камера стрима. Записать палитру и время суток.
1. **Заготовка**: `npm run asset -- newloc locations/<имя>.blend --size 120` — сцена с коллекциями:
   `Ground` (земля), `Colliders` (стены: `COL_…` — коробка, `COL_CYL_…` — цилиндр), `NoScatter` (тропы
   и площадки без мелочи), `Kit_Rocks` (пример кита), `Props` (уникальные объекты).
2. **Блок-аут (серый)**: крупные формы земли (скульпт/модификаторы), основные объёмы, коллайдеры.
   Выгрузка → в игре на стенде проверяем масштаб, проходимость, камеру. Итерации быстрые.
3. **Кит**: модульные детали (стены, полы, колонны, скалы, деревья, пропсы) — источники и подготовка как в
   [models.md](models.md) (`prep` → палитра и бюджеты). Каждая тема — коллекция `Kit_<тема>`; у детали
   можно задать вес выпадения свойством `zep_weight`.
4. **Сборка и детализация**: крупное — руками или скриптом по плану (Claude может сгенерировать раскладку
   из брифа), мелочь — слоями scatter:
   ```
   npm run asset -- scatter locations/<имя>.blend --kit Kit_Rocks --count 300 --min-dist 2 --slope 30 --align
   npm run asset -- scatter locations/<имя>.blend --kit Kit_Grass --density 40 --min-dist 0.6 --avoid NoScatter
   ```
   Правила: плотность или число, расстояние между деталями, наибольший уклон, диапазон высот,
   запретные зоны, разброс масштаба, наклон по нормали. Копии — связанные (общий меш).
5. **Свет и атмосфера**: время суток, туман, акценты (огонь, свечение, цветные пятна), запекание AO.
6. **Выгрузка**: `npm run asset -- location locations/<имя>.blend public/locations/<имя>` →
   - `<имя>.glb` — повторяющиеся детали собраны в `EXT_mesh_gpu_instancing`: Babylon (загрузчик уже
     подключён) делает thin instances, тысяча камней — одна отрисовка на материал;
   - `<имя>.heights.json` — карта высот в формате `src/shared/data/terrainSculpt.json` (для сервера);
   - `<имя>.colliders.json` — коробки и круги стен в игровых координатах;
   - сводка: отрисовки, треугольники, текстуры, предупреждения по бюджету.
   Координаты: точка Blender (X, Y, Z) в игре — (−X, Z, −Y); файлы высот и коллайдеров уже пересчитаны.
7. **Проверка**: сводка бюджетов; стенд — спектатор (`?perf=1`, сводка `[perf10m]` в журнале), Quest —
   metavr; кадры с фиксированных ракурсов (`npm run asset -- preview locations/<имя>.blend …`).
8. **Полировка** по фидбэку: композиция, свет, переходы, звук.

## Интеграция в код (один раз, при первой такой локации)

- Регион мира (как катакомбы — `src/shared/catacombs.ts`): где лежит локация, вход/выход.
- Высоты: сервер и клиент читают `<имя>.heights.json` (как `terrainSculpt.json` в `src/shared/terrain.ts`).
- Коллайдеры: проекция движения героев/ботов/мобов на свободное место (как `catProject`).
- Клиент: загрузка GLB при приближении, отсечение по залам/секторам (как `CatacombsFx.showHalls`).
- Навигация ботов: сетка проходимости по высотам и коллайдерам.
