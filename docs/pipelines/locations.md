# Локации с нуля: от брифа до игры

Цель — локации «как в большой игре», но в бюджете WebGL/Quest. Всё строится генераторами по спецификации
`art/locations/<Имя>.json`: рельеф, раскраска земли, детали (камни, ели, дубы, кусты, трава, цветы, грибы,
пни, брёвна, колонны, руины, щебень, кристаллы, скалы), точки интереса и рассыпка по правилам. Богатство
деталей — за счёт GPU-инстансов: все копии одного вида — **одна отрисовка** (тысяча пучков травы — тоже одна).

## Что значит «ААА» у нас (чек-лист арт-направления)

- **Композиция**: у каждой зоны точка интереса, видная издалека (руины на возвышенности, огромное дерево,
  кристаллы); ведущие линии (тропы, хребты, берег) ведут к ней; ритм открытое/закрытое (поляна ↔ лес).
- **Слои детализации**: крупные формы (рельеф, горы по краю, озеро) → средние (скалы, валуны, деревья,
  постройки) → мелочь (кусты, камни, пни, брёвна) → «ковёр» (трава, цветы, грибы). Каждый слой — свои правила.
- **Переходы, а не швы**: песок у воды, грязь на тропах, скалы на крутых склонах, пласты породы, мох на
  верхушках камней и руин, тень-контакт под каждым деревом и камнем (запекается в цвет земли).
- **Цвет**: палитра локации (`palette`) — 2 оттенка травы + земля + скалы + песок + вода; детали в той же гамме,
  акценты — цветы, ягоды, светящиеся кристаллы. Низ деталей темнее (AO в цветах вершин), верх светлее.
- **Свет и жизнь** (в игре): солнце + туман по глубине, точечные огни ≤ 4 на Quest, огонь/вода/частицы, звук.
- **Края карты**: горы-хребты по периметру (`border`) — мир «закрыт» естественно, без невидимых стен.

## Бюджеты (сводка `location` пишет предупреждения)

| | Quest (VR) | Спектатор 1080p |
|---|---|---|
| Отрисовок в кадре | ≤ 150 | ≤ 300 |
| Треугольников в кадре | ≤ 300–400k | ≤ 800k |
| Динамических источников света | ≤ 4 | ≤ 6 |

Демо `MossGrove` 120×120 м: ~3 300 объектов → **55 отрисовок**, 98k треугольников, GLB 1.7 МБ.

## Цикл работы

1. **Бриф**: назначение (охотничьи угодья 20–30 ур., арена, лагерь), размер, настроение и время суток,
   2–5 картинок-референсов, план-набросок: где вход, где бой, точки интереса, где камера стрима.
2. **Спецификация** — Claude пишет `art/locations/<Имя>.json` (≈60–100 строк, см. ниже).
3. **Сборка + превью**: `npm run asset -- genloc art/locations/<Имя>.json art/build/<Имя>.blend --preview art/build/<Имя>.png`
   → JSON (сетка, высоты, сколько чего поставлено, треугольники вариантов) + лист: карта сверху и три вида
   (с угла, низко сбоку, с тропы глазами героя). 2–3 с.
4. **Итерации числами**: сдвинуть холм, расширить тропу, гуще лес (`density`, `cluster`), поменять палитру,
   добавить точку интереса. Пересборка детерминирована (`seed`): меняется только то, что поправили.
5. **Вместе в Blender** (MCP): `L.build_file(spec, live=True)` — отдельная сцена с именем локации; пользователь
   облетает, говорит правки. Ручную доводку (передвинуть объект) потом переносим в спецификацию.
6. **Выгрузка**: `npm run asset -- location art/build/<Имя>.blend public/locations/<Имя>` →
   `<Имя>.glb` (EXT_mesh_gpu_instancing → thin instances в Babylon, цвета вершин COLOR_0, трава двусторонняя,
   вода полупрозрачная), `<Имя>.heights.json` (формат terrainSculpt, для сервера), `<Имя>.colliders.json`
   (круги стволов/валунов/колонн и коробки стен, игровые координаты). Координаты: Blender (X, Y, Z) → игра (−X, Z, −Y).
7. **Проверка**: сводка бюджетов; стенд — спектатор (`?perf=1`, `[perf10m]`), Quest — metavr.

## Спецификация

```jsonc
{
  "name": "MossGrove", "seed": 7, "size": 120, "res": 1.0,      // размер (м, число или [W, D]), шаг сетки земли
  "palette": {"grass": "#5a8a36", "grass2": "#86b24c", "dirt": "#8e6d48", "rock": "#7d786f",
              "sand": "#cbb98a", "mud": "#4c4434", "water": "#3b7f9c"},
  "rockSlope": 30, "strata": 2.4, "flatGround": "dirt",          // скалы круче 30°, частота пластов, площадки — земля
  "terrain": {
    "noise": [{"amp": 1.6, "scale": 28}, {"amp": 0.35, "scale": 6}],
    "features": [
      {"type": "border", "h": 16, "w": 16, "ridgeScale": 18},     // хребты по периметру
      {"type": "hill", "at": [-32, 30], "r": 22, "h": 7, "sharp": 1},
      {"type": "plateau", "at": [8, 18], "r": 13, "h": 2.2, "edge": 3},
      {"type": "flat", "at": [-20, -26], "r": 8, "blend": 5, "h": 0},   // площадка (h нет — по месту)
      {"type": "crater", "at": [0, 0], "r": 6, "h": 2},
      {"type": "lake", "at": [32, -22], "r": 15, "depth": 2.4, "level": -0.5},
      {"type": "path", "points": [[-58, -38], [-20, -26], [8, 18]], "w": 3.5, "depth": 0.18}
    ]
  },
  "kits": {                       // виды деталей: генератор + число вариантов + параметры (диапазон [min, max] — на вариант)
    "Pine": {"gen": "pine", "variants": 4, "height": [7, 11]},
    "Boulder": {"gen": "rock", "variants": 3, "size": [2.5, 4.5], "flat": 0.6, "sink": 0.15}
  },
  "place": [                      // точки интереса
    {"kit": "Column", "group": "ring", "at": [8, 18], "r": 8.5, "count": 10, "skip": 0.2, "face": true, "clear": 11},
    {"kit": "Wall", "group": "line", "from": [-1, 25], "to": [9, 28.5], "step": 4},
    {"kit": "Rubble", "group": "cluster", "at": [8, 18], "r": 7, "count": 5},
    {"kit": "Boulder", "at": [-24, -22], "rot": 30, "scale": 1.2, "clear": 3}
  ],
  "scatter": [                    // слои рассыпки сверху вниз: крупное раньше мелкого
    {"kit": "Pine", "minDist": 4.5, "density": 0.75, "cluster": [22, 0.5], "slope": [0, 32],
     "height": [-1, 12], "avoid": ["path", "flat", "lake", "plateau:0.5"], "scale": [0.8, 1.25]},
    {"kit": "Grass", "minDist": 1.0, "density": 0.7, "cluster": [9, 0.6], "align": 1.0, "avoid": ["path:0.4", "lake"]}
  ]
}
```

**Генераторы деталей** (`gen`) и их параметры: `rock` (size, flat, base, moss), `cliff` (size), `rubble` (size),
`pine` (height, tiers, leaf, leaf2), `tree` (height, blobs, leaf, leaf2, tris), `bush` (size, berries),
`grass` (size, blades), `flowers` (size, colors), `mushroom` (size, cap), `stump`, `log` (size),
`column` (height, broken), `wall` (length, height, broken), `crystal` (size, base, tip — светится).
Общие для кита: `variants`, `sink` (доля высоты в землю), `collider` (`["cyl", доля]`, `["trunk", доля]`, `["box", 1]`).

**Правила слоя** `scatter`: `minDist` (шаг сетки, м), `density` (доля ячеек 0–1), `cluster: [масштаб, покрытие]`
(пятна-рощи вместо равномерной каши), `slope: [от, до]°`, `height: [от, до]`, `avoid` / `only` — зоны
`path flat lake plateau border` (`:порог` 0–1), `scale`, `align` (наклон по склону 0–1), `block`
(занимает место — следующие слои обходят), `respect` (обходить занятые места), `margin` (отступ от края).
Точки интереса с `clear` расчищают круг от рассыпки.

## Интеграция в игру (один раз, при первой такой локации)

- Регион мира (как катакомбы — `src/shared/catacombs.ts`): где лежит локация, вход/выход, переход.
- Высоты: сервер и клиент читают `<Имя>.heights.json` (как `terrainSculpt.json` в `src/shared/terrain.ts`).
- Коллайдеры: проекция движения героев/ботов/мобов на свободное место (как `catProject`).
- Клиент: загрузка GLB при приближении; материалы — плоский StandardMaterial **с цветами вершин**
  (не терять COLOR_0 при перекраске); отсечение по секторам (как `CatacombsFx.showHalls`).
- Навигация ботов: сетка проходимости по высотам и коллайдерам.
