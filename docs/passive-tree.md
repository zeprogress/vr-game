# Дерево прокачки классов

Макет утверждён 2026-10-27 (артефакт «Дерево воина»). Код — `src/shared/passiveTree.ts`, окно — `src/client/pc/PcTree.ts`.

## Правила

- У каждого класса своё дерево, форма одна (детерминированный генератор, тот же seed), содержимое своё.
- Очко за уровень (`ATTR2.pointsPerLevel = 1`, `startPoints = 1`), узел стоит 1 очко.
- Узел открывается, если взят соседний (или он у корня). Снятие узла снимает всё, что потеряло связь с корнем.
- Атрибуты — сами узлы: узел атрибута даёт `ATTR_NODE` (+4). Поля `str…wis` и `unspent` героя считаются из дерева
  текущего класса (`ZoneRoom.syncTree`), поэтому бой, HUD и сейвы читают прежние поля.
- Класс — по оружию в руках; сменилось оружие — атрибуты пересчитываются от дерева нового класса (проверка в тике).
- Сброс — как раньше у атрибутов (`respecNick`, жетоны ◈), сбрасывает деревья всех классов.

## Форма

- 13 рядов, растёт снизу вверх. Три главных направления (Урон, Защита, Умения) — ряды 2,2,2,2,3,3,3,4,4,4,5,5,5;
  между ними промежуточные ветки (свои у класса) — с 4-го ряда, ширина 1–3.
- Подветки по атрибутам слева направо: урон — СИЛ, ЛОВ, УДЧ; защита — ТЕЛ (две подветки), МДР; умения — МДР, ИНТ.
- Каждый 3-й ряд и нижний — узел атрибута подветки; на вершине у каждой подветки ключевой узел.
- Мосты между направлениями каждые 4 ряда. 168 узлов, 10 ключевых.

## Сохранение

`PlayerRecord.tree: { [класс]: number[] }` — номера взятых узлов. Миграция `ATTR_VER = 3`: пустое дерево,
бесплатный сброс, ботам снова авто-раскладка (`autoTree` по весам `CLASSES2[cls].build`).

## Где тратятся очки

| Где | Как |
|---|---|
| ПК, телефон и `!inv` | вкладка «Дерево и атрибуты» (`PcInventory` → `pcTreePanel`), действие `tree` (idx 1 — взять, 0 — снять); на телефоне первый тап — выбрать узел, второй — взять / снять |
| VR | запястное меню, вкладка «Дерево» (`WristMenu.drawTree`): луч — описание, курок — взять / снять, стик — по узлам |
| Кнопки «+4» у атрибутов (ПК, `!inv`, телефон, VR) | `stat` / `MSG.spend`: ближайший узел этого атрибута с узлами по пути (`takeAttr`) |
| Чат `!str !dex !int !con !luc !wis [N]` | то же, `spendStats` |
| Боты | `botAutoSpend` → `autoTree` |

## Бонусы в бою

Малые узлы несут эффект `fx` (вид `TREE_FX` и доля), сумма по взятым — `treeBonusTotals`, сервер кладёт её в
`PlayerState.tb` (`TreeBonusSync`). Формулы читают `treeBonus(a, вид)` рядом с бронёй, поэтому клиент и сервер считают одинаково:

| Вид | Где действует |
|---|---|
| dmg | `physPower2` (физ. урон) |
| atk | `physTempo2`, `castTempo2`, `meleeSpeedFor` (темп атак и каста) |
| crit, critDmg | `critChance2`/`critMult2` и серверный `rolledCrit` |
| dodge, hp, regen, physDef | `dodge2`, `maxHp2`, `hpRegenFrac`, `armorFrac` |
| magDef, magic, heal | `magicResistFrac`, `magicPowerFor`, `healAmountFor` |
| move | `moveSpeed2` |
| cd | `skillCdMul2` (вместе с ожерельем, не ниже половины) |
| block, vamp, pierce | `blockChanceOf` (только со щитом), `heldVamp`, `heroRoll("pierce")` |
| skill | `ZoneRoom.skillHitMob` (урон умений и ульты) |

Узел без механики — `active: false`, в окне пунктирная точечная рамка и «пока не действует».

## Улучшения умений (★) и ключевые узлы (◆)

`treeSkillState(cls, taken)` собирает прибавки к умениям и особые механики, сервер кладёт их в `Runtime.treeSkill` /
`Runtime.treeKey` (в `syncTree`). `castSkill` берёт `skillModsFor(rt.treeSkill, kind)` («*» — для всех умений):

| Прибавка | Где |
|---|---|
| rad, radMul | радиус зоны (`sk.radius`, `RAD`; отдельно — Разрывная, Стягивание) |
| dur, durMul | длительности (`DUR`, метка, печать, клич, дым, призрак, паутина) |
| stun, stunAdd, slow | помощники `stun` / `slow` (и `root` для паутины) |
| dmg, dmgMul | `sk.dmgMult`, урон ауры стали, яд Чумного клинка |
| heal, healMul | Аура исцеления, Печать света, Стрела жизни, Кража душ |
| count | удары вихря, выпады, копья ливня, волны огненного дождя и шквала, стрелы роя, прыжки цепи |
| range | цель умения, `clampPoint`, отскок, рой |
| cdAdd | откат |

Особые механики (`KeySpecial`): добивание и урон по оглушённым и «Снайпер» (`treeDmgMul` — удары и умения),
двойной удар каждые N атак (`heroHitRoll`), серия критов после рывка, «Поток» (бесплатный откат), лечение союзников
при касте, «Стена копий»; во входящем ударе (`hurtPlayer`) — неуязвимость или «тень» после уворота, блок снимает
оглушение, отражение при блоке. У ботов входящий урон идёт другим путём — механики уворота/блока на них не действуют.

Тексты нескольких ключевых узлов переписаны под то, что считает бой (Двуручный размах, Боевой посох, Благодать,
Пронзатель, Бронированный, Ясный разум, Фаланга, Громоотвод, Мученик, Чума, Охотничья сеть, Стена копий; ★ Шквал стрел — «+1 волна»).

## Особые малые узлы

`SPECIAL_SMALL` в `passiveTree.ts` → `KeySpecial` (сервер, `rt.treeKey`) или прибавка ко всем умениям:
Восстановление и Кража жизни (умение лечит героя, `castSkill`), Ответный удар (при блоке, `hurtPlayer`),
Слабое место (по своей метке, `treeDmgMul`), Заслон (союзник в 8 м, `hurtPlayer`), Кровопускание (веер ножей,
отрава), Отрава и Отталкивание (`heroStrike`), Крепкая стойка (`hurtPlayer`), Зоркость (дальность всех умений).
Скрытность и Длинное древко — обычные бонусы (уворот, урон). Тексты Зоркости, Скрытности, Крепкой стойки,
Длинного древка, Восстановления и Кражи жизни переписаны под то, что считает бой.

Все 168 узлов у всех классов действуют в бою (тест «все узлы действуют в бою»).
