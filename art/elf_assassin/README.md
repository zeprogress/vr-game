# Эльф-ассасин — ортографическая T-pose схема (5 ракурсов)

Пакет референсов для перевода в 3D-модель. Всё отрендерено из одного и того же процедурного прокси-меша
(скрипт `elf_assassin.py`, Blender 5.2 + Cycles, CPU), поэтому все ракурсы идеально согласованы между собой.

## Правила, по которым сделан лист

* **Строгая T-поза**: плечи горизонтальны (90° к корпусу), предплечья без сгиба, ладони вниз, кисти
  держат два кинжала рукоятями в ладонях клинками вниз; ноги прямые, стопы плоские и параллельные.
* **Ортографические проекции** (без перспективы), **единый масштаб во всех 5 видах** — 1 м = 1/2.1 кадра,
  рост персонажа 1.84 м, ноги на z = 0.
* **Светлое фоновое поле** — плоский, однородный светлый фон. Тени полностью исключены: лучи камеры
  не попадают на пол (объекты-приёмники камеры), освещение связано только с коллекцией персонажа.
* **Мягкий рассеянный свет** — большой симметричный набор area-ламп вокруг персонажа + ровный ambient.
* Никаких обрезаний по краю кадра; весь персонаж влезает в каждый вид целиком.

## Разметка листа (для 3D)

* Серо-синяя сетка - **0.5 м**, красная линия - **пол (z = 0)**, красная вертикаль - **ось симметрии**.
* Голубой крест - ось рук (z = 1.505 м), метки запястья/пальцев; кружки - колени/лодыжки.
* Палитра внизу - базовые цвета материалов (для текстур и vertex color).

## Как переделать / перерендерить

```bash
# полный рендер (5 видов 4096 px + листы + экспорты), ~40 мин на 8-ядерном CPU
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python elf_assassin.py

# быстрый низкий превью (1024 px, 16 сэмплов), без экспортов
... --python elf_assassin.py -- --quick --no-export

# только собрать листы из уже отрендеренных views/*
python3 make_sheets.py      # пересобрать листы из views/*
... --python elf_assassin.py -- --post   # только повторные экспорты (glb/bvh/blend)
```

Параметры (цвета материалов, пропорции, поза) — в начале `elf_assassin.py` (`make_materials()`,
`J` — суставы, `build_body()`, `build_head()`, `build_weapons()`).
