# VR GAME

VR MMORPG (пет-проект). Общий мир: VR (Quest 2/3), браузер на десктопе, телефон.
Полный план разработки — в [PLAN.md](PLAN.md).

## Текущий этап: 3+ — зона, меч, куклы-мишени

Вид от первого лица работает от любого источника ввода:
- **Десктоп:** WASD + мышь (pointer lock), `Space` — прыжок, `E` — взять/бросить меч, ЛКМ — удар.
- **Телефон:** левый джойстик — движение, свайп справа — осмотр, ⚔ — удар, ✋ — взять меч, ⤴ — прыжок.
- **VR:** левый стик — движение (относительно взгляда), правый стик влево/вправо —
  поворот щелчками (snap-turn), trigger — удар, grip — взять меч, A — прыжок.
  Кнопка «Enter VR» появляется сама, если гарнитура доступна.

Зона: рельеф из шума, небо с градиентом и облаками, деревья, трава, туман.
На камне лежит меч — подойди и возьми. Четыре неподвижные куклы: бей мечом,
после трёх попаданий падают и через 4 с воскресают.

Устройство определяется автоматически. Коллизии и гравитация — на лучах (raycast).
Попадание мечом — по кратчайшему расстоянию между клинком и телом куклы. Пока без сервера.

## Запуск

Двойной клик по `start.command` (macOS), либо:

```bash
npm install
npm run dev
```

http://localhost:5173 — десктоп/телефон. Телефон в той же Wi-Fi: адрес из строки **Network**.

### Проверка на Quest 2/3

WebXR требует HTTPS. Запусти с самоподписанным сертификатом на всю локальную сеть:

```bash
npm run dev:vr
```

На Quest открой `https://<IP-компа>:5173` (адрес из строки **Network**), прими
предупреждение о сертификате → кнопка «Enter VR».

## Структура

```
index.html                       страница + canvas
src/
  main.ts                        точка входа, выбор режима подсказки
  shared/constants.ts            игровые числа (позже переедет в пакет shared/)
  engine/Game.ts                 Engine + Scene + рендер-луп, выбор ввода, WebXR
  world/
    Zone.ts                      сборка зоны: свет, небо, рельеф, деревья, куклы
    Terrain.ts                   рельеф из синусов + heightAt(x,z)
    Sky.ts                       градиентный купол, туман, облака
    props.ts                     деревья (инстансы) и трава (thin-инстансы)
  items/Sword.ts                 меш меча
  combat/
    Dummy.ts                     кукла-мишень: удар, качание, падение, респаун
    CombatSystem.ts              взятие меча, взмах, проверка попаданий
  input/
    InputSource.ts               интерфейс ввода + InputState
    DesktopInput.ts              клавиатура + мышь
    TouchInput.ts                экранные джойстик и кнопки
    XRInput.ts                   VR-контроллеры (Gamepad API)
  player/PlayerController.ts      движение от первого лица, raycast-коллизии, VR-риг
```

Числа боя и мира — в `src/shared/constants.ts` (`COMBAT`, `WORLD`).
Посадка меча в руке настраивается константами `EQUIP_*` в `combat/CombatSystem.ts`.

Реструктуризация в монорепо (client / server / shared) — на этапе 4 (см. PLAN.md).
