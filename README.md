# VR GAME

VR MMORPG (пет-проект). Общий мир: VR (Quest 2/3), браузер на десктопе, телефон.
Полный план разработки — в [PLAN.md](PLAN.md).

## Текущий этап: 4 — сервер и мультиплеер-движение

Вид от первого лица работает от любого источника ввода:
- **Десктоп:** WASD + мышь (pointer lock), `Space` — прыжок, `E` — взять/бросить меч, ЛКМ — удар.
- **Телефон:** левый джойстик — движение, свайп справа — осмотр, ⚔ — удар, ✋ — взять меч, ⤴ — прыжок.
- **VR:** левый стик — движение (относительно взгляда), правый стик влево/вправо —
  поворот щелчками (snap-turn), trigger — удар, grip — взять меч, A — прыжок.
  Кнопка «Enter VR» появляется сама, если гарнитура доступна.

Зона: рельеф из шума, небо с градиентом, солнцем и облаками, деревья, трава, туман.
На камнях лежат **меч** и **лук** — подойди и возьми (`E` / grip; повторное нажатие — бросить).
Четыре неподвижные куклы: бей мечом или стреляй из лука, после трёх попаданий
падают и через 4 с воскресают. Дальше по полю скачут **Слизни** (ур. 1) и
стоят поодаль **Плевуны** (ур. 2, вдвое живучее, плюются шариками — целят по
текущему месту игрока, гасятся щитом и застревают в деревьях; урон чуть
больше слизня). У ближних мобов в поле зрения — подпись с именем и уровнем (её загораживают
преграды); удары мечом оставляют раны в точке касания, стрелы
торчат в теле и едут вместе с мобом. Оттолкнуть моба можно, просто прислонив
к нему меч или щит.

**Лук:** в плоском режиме — держи ЛКМ (натяг), отпусти — выстрел по направлению
взгляда; сила = длительность натяга. В VR — держи лук в правой руке, левой рукой
возьмись за тетиву (левый trigger рядом с луком) и оттяни; отпусти trigger — выстрел.
Стрелы летят по баллистике и втыкаются в цель/землю.

**Звук:** процедурный (Web Audio, без файлов) — шаги, прыжок, приземление, взмах
и удар мечом, натяг/выстрел лука, попадание стрелы.

Устройство определяется автоматически. Коллизии и гравитация — на лучах (raycast).
Попадание — по кратчайшему расстоянию между оружием/стрелой и телом куклы. Пока без сервера.

## Мультиплеер (этап 4)

`start.command` поднимает игровой сервер (Colyseus, :2567) + клиент. На входе —
экран с ником: «Играть» (онлайн) или «Играть офлайн». Игроки в одной зоне видят
друг друга (капсула + ник у плоских, голова + кисти у VR), движение сглажено
интерполяцией. Мобы и манекены пока у каждого свои (общие — этап 6). Сервера
нет → тихий откат в одиночный режим.

### Тест вдвоём с разных устройств

`start.command` работает только в своей Wi-Fi. Чтобы пустить друга снаружи —
`share.command` (двойной клик): поднимает сервер + клиент и делает временный
публичный HTTPS-адрес через **Cloudflare Tunnel**. В консоли появится
`https://…​.trycloudflare.com` — открой его сам и дай другу (работает на Quest,
телефоне, чужом ПК; WebXR доволен — адрес по HTTPS). Живёт, пока окно открыто.

Нужен `cloudflared` (`brew install cloudflared`) — `share.command` предложит
поставить. Вручную: `npm run server` + `npm run dev` + `npm run tunnel`.

> Свой сервер держится на твоём Mac всё время сессии. Постоянный хостинг
> (Node + WebSocket, always-on) — это VPS на этапе 11; бесплатный
> `*.beget.tech` — обычный PHP-хостинг, игровой сервер там не поднять.

## Запуск

Двойной клик по `start.command` (macOS), либо:

```bash
npm install
npm run dev
```

http://localhost:5173 — десктоп/телефон. Телефон в той же Wi-Fi: адрес из строки **Network**.

### Проверка на Quest 2/3

WebXR требует HTTPS. Запусти с самоподписанным сертификатом на всю локальную сеть:

```bash
npm run dev:vr
```

На Quest открой `https://<IP-компа>:5173` (адрес из строки **Network**), прими
предупреждение о сертификате → кнопка «Enter VR».

## Управление

**Плоский режим:** `WASD` — движение, мышь — обзор, `Space` — прыжок, `E` — взять
предмет (удерживать = замах, отпустить = метнуть), `ЛКМ` — удар, `C` — панель персонажа.

**VR:** grip — взять/бросить предмет (отпускаешь = метаешь со скоростью руки),
левый стик — движение, правый — snap-turn, `A` — прыжок, `Y` (левый) — панель
персонажа (в ней правый стик выбирает характеристику, курок вкладывает очко).
**За спину:** заведи руку с предметом за плечо и отпусти grip — предмет
убирается за спину той же руки; заведи пустую руку за плечо и нажми grip —
достаёшь обратно. У каждой руки свой слот. Положение на спине крутится из
консоли: `game.stowConfig()`.

Щит берётся в свободную руку и надевается только вместе с мечом. Блок: щитом —
широкий сектор, урон гасится полностью; мечом — узкий сектор, проходит 25% урона
от удара моба, но плевок меч отбивает целиком.

### Настройка предметов и рук

**Прямо в шлеме — кнопка B на правом контроллере.** Панель висит над правой
кистью:

| Управление | Действие |
|---|---|
| правый стик ↕ | выбрать строку |
| **X** (левый) / **Y** (левый) | уменьшить / увеличить |
| **A** (правый) | шаг: крупный (90° / 0.1) → средний → точный |
| **B** (правый) | закрыть |

Открывается панель только **пятикратным нажатием B за 3 секунды** (чтобы не
всплывала случайно); открытую закрывает одиночный B.

Первая строка — что настраиваем (кисти и все предметы для каждой руки), внизу
два пункта: **«Сохранить настройки»** (запоминает всё разом, показывает
`сохранено ✓`) и **«Сброс к файлу»** для текущей цели. Правка отдельного
значения сохраняется и сама — пункт нужен, чтобы зафиксировать всё одним
нажатием и увидеть подтверждение. Изменения применяются сразу и переживают
перезагрузку. Ходить и поворачиваться при открытой панели можно.

Строка **«Сохранить настройки»** в панели пишет числа прямо в
[src/config/loadout.ts](src/config/loadout.ts) через дев-сервер — файл в git,
общий для всех адресов и устройств. В строке видно `в файл ✓`. Пока крутишь
значения, каждая правка ещё и кэшируется локально (`localStorage`), чтобы
случайный выход из VR ничего не терял; «Сохранить» переносит всё в файл и
чистит кэш.

Правка файла руками тоже работает на лету (Vite HMR) и **побеждает** панельную
настройку той же цели. Вне дев-сервера (собранная игра) панель сохраняет только
в `localStorage`, а он привязан к адресу — `https://<IP>:5173` и
`https://localhost:5173` это разные хранилища.

`game.printLoadout()` в консоли печатает текущие значения готовым блоком.

Если кнопка не срабатывает — зажми её и посмотри индекс, потом поставь его в
`LOADOUT.buttons`:

```js
game.vrButtons()   // покажет, какие кнопки нажаты на каждом контроллере
```

## Структура

```
index.html                       страница + canvas
src/
  main.ts                        точка входа, выбор режима подсказки
  config/loadout.ts              ПОЛОЖЕНИЕ ПРЕДМЕТОВ И КИСТЕЙ + кнопки (живая правка)
  shared/constants.ts            игровые числа (позже переедет в пакет shared/)
  engine/Game.ts                 Engine + Scene + рендер-луп, выбор ввода, WebXR
  world/
    Zone.ts                      сборка зоны: свет, небо, рельеф, деревья, мобы
    Terrain.ts                   рельеф из синусов + heightAt(x,z)
    Sky.ts                       градиентный купол, туман, облака
    props.ts                     деревья (инстансы) и трава (thin-инстансы)
  audio/Sfx.ts                   процедурные звуки на Web Audio
  items/
    Sword.ts / Bow.ts / Shield.ts   меши предметов
  combat/
    Dummy.ts                     кукла-мишень: удар, качание, падение, респаун
    Mob.ts / MobSystem.ts        слизни и плевуны: AI, снаряды, раны, опыт
    NameTag.ts                   плашка «имя + уровень» над мобом
    Arrow.ts                     стрела: баллистика + попадание, втыкается
    CombatSystem.ts              предметы в руках, броски с физикой, удары, блок
  shared/geometry.ts             segmentDistance, clamp
  input/
    InputSource.ts               интерфейс ввода + InputState
    DesktopInput.ts              клавиатура + мышь
    TouchInput.ts                экранные джойстик и кнопки
    XRInput.ts                   VR-контроллеры (Gamepad API)
  player/
    PlayerController.ts          движение от первого лица, raycast-коллизии, VR-риг
    Hands.ts                     кисти с пальцами на контроллерах
    Progression.ts               уровни, опыт, характеристики
  ui/
    Hud.ts                       полоса здоровья, вспышка урона, панель на C
    HealthBar3D.ts               полоски здоровья в мире (параллельны горизонту)
    WristPanel.ts                панель персонажа на левой руке (VR, кнопка Y)
    LoadoutPanel.ts              настройка экипировки на правой руке (VR, кнопка B)
    VrVignette.ts                виньетка урона на шейдере
```

Числа боя и мира — в `src/shared/constants.ts` (`COMBAT`, `BOW`, `ARROW`, `WORLD`,
`MOB`, `PROGRESSION`, `SHIELD`). Положение предметов в руках — в
`src/config/loadout.ts` (правится на лету, см. выше).

Реструктуризация в монорепо (client / server / shared) — на этапе 4 (см. PLAN.md).
