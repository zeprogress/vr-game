# VR GAME

VR MMORPG (пет-проект). Общий мир: VR (Quest 2/3), браузер на десктопе, телефон.
Полный план разработки — в [PLAN.md](PLAN.md).

## Текущий этап: 2 — абстракция ввода + тач

Вид от первого лица работает от любого источника ввода:
- **Десктоп:** WASD + мышь (pointer lock), `Space` — прыжок, `E` — взаимодействие.
- **Телефон:** левый джойстик — движение, свайп справа — осмотр, кнопки ⚔ / ✋ / ⤴.

Устройство определяется автоматически. Коллизии и гравитация — на лучах (raycast).
Без сервера. VR — этап 3.

## Запуск

Двойной клик по `start.command` (macOS).

Или вручную:

```bash
npm install
npm run dev
```

Открыть http://localhost:5173. Кликнуть по подсказке — захват мыши.
`WASD` — движение, мышь — камера, `Esc` — выйти из захвата.

С телефона в той же Wi-Fi: адрес из строки **Network**, которую печатает Vite.

## Структура

```
index.html                       страница + canvas
src/
  main.ts                        точка входа, выбор режима подсказки
  shared/constants.ts            игровые числа (позже переедет в пакет shared/)
  engine/Game.ts                 Engine + Scene + рендер-луп, выбор InputSource
  world/Zone.ts                  земля, свет, препятствия
  input/
    InputSource.ts               интерфейс ввода + InputState
    DesktopInput.ts              клавиатура + мышь
    TouchInput.ts                экранные джойстик и кнопки
  player/PlayerController.ts      движение от первого лица, raycast-коллизии
```

Реструктуризация в монорепо (client / server / shared) — на этапе 4 (см. PLAN.md).
