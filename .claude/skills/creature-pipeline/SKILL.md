# Существо по образцу Ледяного гиганта

Полное описание — `docs/pipelines/creatures.md` (прочитать перед работой: там правила качества по каждому
слою и таблица файлов-образцов). Здесь — порядок работы и проверки.

## Главное правило

Клип, телеграф на земле, урон сервера, эффект и звук бьют **в один кадр**: длительности и кадры ударов —
одни числа в `src/shared/mobs.ts` (как `ICE_GIANT.clipSec`, `strikeDelay`, `windup`), скрипт клипов держит
те же `*_SEC` / `*_HIT`. Act-обработчик эффектов один на игру, спектатора и лабораторию.

## Порядок

1. **Дизайн.** Роль (танк для толпы, дальник, страж, рейд-босс), место, уровень, одна сквозная тема, 3–5
   умений: удар, круг против толпы, бросок по дальним, линия, ярость на доле HP. Каждое умение — телеграф →
   удар → след, из-под удара можно уйти, оглушение срывает замах. Таблица пользователю: умение | кд |
   замах | радиус | урон | эффект | клип | звук. Если бриф размытый — сначала таблица, потом код.
2. **Модель и риг.** Модель пользователя → `art/models/<Имя>.json` (`"rig": "fit"`) → `fit_rig.py` → `.blend`
   с видимыми костями. **Суставы расставляет пользователь** (`art/build/<Имя>_rigZEP.blend`) — остановиться
   и отдать файл. Потом считать суставы, пересобрать веса, `npm run asset -- weights …`.
3. **Клипы.** `tools/blender/<имя>_anim.py` по образцу `icegiant_anim.py` на `zep_gen/keyanim.py`
   (`K`, `BipedPose`, `biped_gait`, `shake`). Сборка `npm run asset -- anim …`, проверка глазами
   `npm run asset -- frames …` (раскадровка) и цифрами `npm run asset -- feet …` (стопы на земле в опоре,
   не под землёй). Правим, пока не ровно.
4. **Сервер.** `ELITE_MOBS` + константы умений в `src/shared/mobs.ts`, `MOB_SWING`, `ZoneSim.tick<Имя>`,
   act-события в `ActKind` (`src/shared/net/messages.ts`), стаки — `ZoneRoom.hurtPlayer`, опасные зоны
   ботам — `addDanger`. Тест `tests/server/<имя>.test.ts`. Не добавлять поля в `ZoneState` (предел 64).
5. **Эффекты.** `src/client/ui/<Тема>Fx.ts` (шейдеры, пул, без клонов материалов, MULTIVIEW) +
   `src/client/ui/<Имя>Act.ts`; вызов в `Game.ts` и `Spectator.ts`; `Mob.ts`: `SWING_ANIM`, `blendAnims`,
   шаги по фазе клипа, аура, своя смерть, предзагрузка звуков.
6. **Звук.** `tools/sfx/<имя>_sfx.py` на `tools/sfx/sfxlib.py`; голоса — из неиспользованных сэмплов
   `ASSETS/SFX`; пик звука — в кадр удара; короткие WAV, длинные MP3; спектры —
   `python3 tools/sfx/spectrogram.py`. Карта звуков и предзагрузка — `src/client/audio/Sfx.ts`.
7. **Лаборатория.** `src/client/lab/sceneFx<Имя>.ts` в `lab.html?s=fx`: кнопки — умения целиком через тот
   же Act-обработчик. Ручная подгонка чисел — живая панель `?<имя>=1`.
8. **Проверка.** `npm test`, `npm run typecheck`, `npm run build`; скрипт размещения (пол, свод, соседи,
   центр стоянки = центр зоны). Живой бой — `npx tsx scripts/stage-mob-test.mts <model>` **только на стенде
   и только с разрешения пользователя**. Локальный коммит; деплой — только по слову «деплой».

## Переделка старого моба

Сначала инвентаризация (модель, клипы, механики, события, звуки, кто ещё их использует). Ключи не менять:
id в `ELITE_MOBS`, ключ модели в `MODELS`, `type` в лагерях — на них завязаны сейвы, квесты, лагеря,
события. Новый GLB — под тем же ключом модели.

## Герои

Числа — `src/shared/classes2.ts` (`SKILLS2`), сервер — `ZoneRoom.castSkill`, эффекты — `ClassFx.playClassAct`
+ `SkillVfx` (цвет по смыслу: `FX_ROLE`), лаборатория — `lab.html?s=classes` и `?s=fx`. Паритет: ПК,
телефон (третье лицо), VR (первое лицо), спектатор. Клипы героя — скелет `CharacterArmature`: нужен свой
класс позы, `biped_gait` как есть не подходит.

## Отчёт пользователю

Отдельно: что проверено машиной (тесты, раскадровка, стопы, спектры, бой на стенде) и что ждёт его
игровой проверки (звук на слух, баланс, свет модели `?moblight=1`). Числа — первая прикидка.
